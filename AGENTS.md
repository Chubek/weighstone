# Weighstone developer guidance

Weighstone is a C++20 header-only library. Put public compiler-integer features under `include/Weighstone/CCINT/`, generic reusable helpers under `support/`, executable regressions under `tests/` and sample use under `examples/`. Never add empty feature headers implying an implemented capability. Update the 40-chapter manual through `tools/build_manual.py`, which also rebuilds `MANIFEST.yaml`. Preserve public semantics for mathematical integers vs fixed-width machine integers. Use tri-state `Verdict` for potentially inconclusive analyses; never turn `unknown` into `proven`. For every new rewrite add a positive, boundary and failure/unknown test. Run `cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug && cmake --build build && ctest --test-dir build --output-on-failure`.
